Overview

KubePilot ("we", "our", or "the app") is a mobile application that lets you connect to and manage Kubernetes clusters — including Amazon EKS clusters — directly from your iOS or Android device.

Your privacy is important to us. This policy explains exactly what data the app accesses, how it is used, and where it is stored. The short answer:

KubePilot stores all credentials and cluster data locally on your device only. We do not operate any backend servers, we do not collect analytics, and we do not sell or share your data with any third party.

Information We Handle

The following data is entered by you and used solely to connect to your own infrastructure:

Data Purpose Storage
Cluster endpoint URL Sending API requests to your Kubernetes cluster Device only
CA certificate (base64) TLS verification of the cluster's API server Device only
Client certificate & key Mutual TLS authentication (kubeconfig clusters) Device only
Bearer / service-account token Kubernetes API authentication Device only
AWS Access Key ID & Secret Generating short-lived STS tokens for EKS clusters Device only
AWS Session Token (optional) Support for temporary IAM credentials Device only
EKS cluster name & region Constructing STS presigned URLs for token generation Device only
Kubernetes resource data
(pods, deployments, logs, etc.)		 Displaying live cluster state in the app UI In memory only

All persistent data is stored using the device's local encrypted storage (AsyncStorage). It never leaves your device except as part of direct API calls to your own cluster or your own AWS account.

How Data Is Used

Your data is used exclusively for:

  • Authenticating to Kubernetes API servers you configure
  • Fetching and displaying live cluster resources (pods, deployments, services, etc.)
  • Performing management actions you explicitly trigger (scale, restart, delete)
  • Generating short-lived EKS bearer tokens via AWS STS — sent only to your own AWS account

We do not use your data for advertising, profiling, analytics, or any purpose beyond the cluster management features visible in the app.

Network Requests

The app makes outbound network requests only to endpoints you control or own:

Destination When What is sent
Your Kubernetes API server Every time you view or act on a cluster resource Your bearer token + the API request
sts.<region>.amazonaws.com EKS connections only — once per request to fetch a 60-second token SigV4-signed presigned URL (no secrets transmitted in plain text)

No data is sent to any KubePilot-operated server. There is no telemetry, crash reporting, or analytics SDK included in the app.

Data Storage & Security

  • Local storage only — connection profiles, certificates, and AWS credentials are persisted using AsyncStorage on your device.
  • OS-level protection — on both iOS and Android, app data is sandboxed and protected by the operating system's built-in encryption and access controls.
  • No cloud sync — we do not sync, back up, or mirror your data to any cloud service.
  • Short-lived tokens — EKS tokens are generated fresh for each request and expire after 60 seconds. Long-term AWS credentials remain on your device and are never transmitted as part of the signed request.

We recommend using IAM credentials scoped with least-privilege permissions and, where possible, using short-lived session credentials.

Third-Party Services

KubePilot does not integrate any third-party analytics, advertising, crash-reporting, or social SDKs.

The only external service the app communicates with is AWS Security Token Service (STS), and only when you configure an Amazon EKS cluster. That communication is between your device and your own AWS account — KubePilot is not a party to that data.

AWS's own privacy practices are governed by the AWS Privacy Notice .

Children's Privacy

KubePilot is a professional developer tool intended for adults. It is not directed at children under the age of 13 (or the applicable age in your jurisdiction). We do not knowingly collect personal information from children. If you believe a child has provided information through the app, please contact us so we can address it.

Your Rights & Data Control

Because all data lives exclusively on your device, you have complete control over it:

  • Delete a connection — remove any cluster profile from within the app's Settings screen.
  • Delete all data — uninstalling the app removes all stored credentials and connection profiles from your device.
  • No account required — KubePilot has no sign-up, no account, and no server-side profile associated with you.
